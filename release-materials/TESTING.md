# 免费测试发行验证记录

版本：0.7.20-applemusic.beta.1；测试日期：2026-10-17。

## 环境与范围

- 本机 macOS Apple Silicon arm64；使用隔离用户配置，不复制日常资料库缓存、账号或 API 密钥。
- 独立构建使用 npm 锁定依赖和 Electron 43.7.5，不依赖已安装 Folia；运行时声明最低 macOS 12。
- 不是第二台实体 Mac 测试，不能代表所有 macOS 版本、地区、订阅或账号。

## 已有验证

- Apple Music 专项测试及类型检查：通过；首次自动连接并发合并、拒绝授权不重复弹窗、断开连接后不自动重连纳入测试。
- 上一轮播放引擎验证：本机实际 Apple Music 资料库、完整歌曲播放、暂停、进度、切歌、封面及网易云逐字歌词已验证；免费发行轮不主动切换用户当前歌曲。
- 歌词自动匹配、翻唱/现场版过滤、手动预览与持久保存、AI 缺词输入、原有歌词处理：有专项测试覆盖。
- 当前 AI 实际模型请求需要使用者配置；隔离配置只验证接口存在、未配置提示及备用主题路径，不宣称完成真实付费模型的全链路测试。

## 本次最终产物验收

- 49 项相关测试通过（10 个测试文件），类型检查通过。
- 独立构建应用在全新隔离配置下启动成功；首次系统确认后自动连接“音乐”，资料库读取与网易云歌词请求通过。
- 原作者 LICENSE、NOTICE 和第三方说明已在打包应用内验证存在。
- 原项目更新检查已验证禁用；验证过程未调用 play/pause/seek，不改变用户当前播放。
- DMG 和源码压缩包的最终校验见 `PACKAGE_CHECKS.json` 与 `SHA256SUMS.txt`。
- 首次测试受到系统钥匙串窗口阻塞，用户自行确认后重跑通过；首次资料库状态检查未通过，系统确认完成后的全新配置复测通过。保留此记录，不把首次失败隐藏为“从未出现问题”。

## 未验证 / 发布限制

- Intel 实机、第二台实体 Mac、所有受运行时声明支持的 macOS 版本。
- 无订阅/地区无版权等账号组合下的完整线上矩阵。
- Apple Music 受保护音频的 PCM 分析、声部分离与音频导出不属于本版可用能力。
- Apple 的首次授权、Gatekeeper 提示和钥匙串提示仍需用户本人操作。
