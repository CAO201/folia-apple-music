# 免费测试发行验证记录

## beta.4：外区名称与四来源补全（2026-10-18）

- TypeScript 检查通过；156 项针对性单元测试通过，覆盖别名双向匹配、版本/时长拒绝、优先级、独立来源超时、冷却、取消及缓存身份隔离。
- 8 项 Playwright 组件测试通过：实际播放累计 5 秒触发、暂停排除、切歌不串词、后台结果不覆盖手动歌词、前奏不误触发、页面重载后离线读取 IndexedDB 缓存，以及原逐句打点回归。
- `scripts/apple-music/verify-external-lyrics.mjs` 只请求公共目录与歌词，不控制播放。实测网易云《十年》、QQ/酷狗《晴天》及 LRCLIB《Yellow》取得可解析的时间轴；酷狗和网易云样本含逐字时间。外部服务中途出现过 LRCLIB HTTP 503，后续复测成功，不能据此承诺服务长期可用。
- 歌词来自运行时网络读取，报告只记录来源、数量及通过状态，不保存或分发完整样本歌词。安装包内 IPC 验证见 `RECOVERY_CHECKS.json`；DMG 挂载/拷贝/签名及许可验证见当前版本 `PACKAGE_CHECKS.json`。
- Apple 云端官方歌词仍未接入。未增加封面识别依赖；封面共用不能证明同一录音。
- 下方 beta.3/beta.2 记录及 `LYRIC_CHECKS.json`、`SEARCH_CHECKS.json` 保留为对应历史版本记录，不代表本轮重新执行全部旧场景。

## beta.2 搜索修复验证（2026-10-18）

- 版本 0.7.20-applemusic.beta.2；类型检查及 76 项相关测试通过，覆盖查询失败降级、地区缓存隔离、切区时的过期响应、分页、命令文案，以及原有歌词/主题测试。

- 从最终 DMG 只读挂载并复制的安装包：CN“陈奕迅”返回 21 首；TR“周杰伦”返回 194 条候选、TR“Eason Chan”返回 177 条候选，两项均验证前后两页无重复且地区正确。详见 SEARCH_CHECKS.json。

- 最终 DMG 的临时签名、复制后载荷一致性、原作者署名和第三方对应源码校验通过。全新配置自动连接、资料库读取及网易云歌词请求通过；没有发送 play/pause/seek。
- 初次构建因本地 node_modules 链接漏收运行依赖，该产物未发布；改用项目内实体依赖后重新打包，核对 conf / express 等依赖，并通过应用实测。

- 最终搜索专项复测时新配置曾再次丢失连接状态；测试脚本明确记录 reconnected=true，通过一次标准连接请求后 CN/TR 均通过。此项与已独立通过的自动连接检查分开，不将重连记为首次自动连接成功；本轮按要求未修改生产自动连接实现。
- 只在本机 Apple Silicon 验证，不代表 172 个地区的账号和版权组合均经过实测。

## 环境与范围

- 本机 macOS Apple Silicon arm64；使用隔离用户配置，不复制日常资料库缓存、账号或 API 密钥。
- 独立构建使用 npm 锁定依赖和 Electron 43.7.5，不依赖已安装 Folia；运行时声明最低 macOS 12。
- 不是第二台实体 Mac 测试，不能代表所有 macOS 版本、地区、订阅或账号。

- Apple Music 专项测试及类型检查：通过；首次自动连接并发合并、拒绝授权不重复弹窗、断开连接后不自动重连纳入测试。

- 歌词自动匹配、翻唱/现场版过滤、手动预览与持久保存、AI 缺词输入、原有歌词处理：有专项测试覆盖。
