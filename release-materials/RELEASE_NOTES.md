# Folia Apple Music 0.7.20-applemusic.beta.2

**免费测试版 / macOS Apple Silicon / 未经 Apple 公证 / 建议标记为 GitHub Pre-release**

基于 [Folia](https://github.com/chthollyphile/folia-major) v0.7.20。原作者 **chthollyphile 与 Folia 原项目贡献者**；保留原有署名、AGPL-3.0 许可证和第三方致谢。此版本为非官方修改版。

## beta.2 搜索修复

- 修复搜索入口残留旧平台来源、资料库失败时阻断 Apple 目录查询的问题。
- 默认搜索地区为中国大陆（CN）；首次搜索要求确认，可从 Apple 官方地区入口列表筛选 172 个地区并记住选择，命令面板也可修改。
- 增强外区中文搜索：繁简体与常见歌手中英文别名辅助查询，TR 实测覆盖“周杰伦”与英文歌手名。
- 修复分页遗漏和重复、切换地区后的过期结果覆盖；目录与资料库独立返回，失败时显示具体原因。
- 其他播放、歌词与视觉功能保持原有实现。

每次查询读取最多 200 条 Apple 目录候选与 100 条资料库候选后合并分页；CN 等公开接口无结果的地区使用 Apple 官方音乐网页补充并读取同区歌曲信息，网页候选通常较少。这不是无限目录检索。搜索地区只影响目录，不改变 Apple 账号地区；播放范围与此前相同，未加入资料库的目录歌曲会在系统“音乐”打开，加入资料库后可在 Folia 播放。

## 保留功能

- 保留 Folia 界面、主题、背景、歌词动画和播放队列。
- 音频仅通过 macOS 系统“音乐”App 播放 Apple Music 资料库歌曲；首次打开自动启动“音乐”并请求用户确认连接，选歌后开始播放。
- 网易云仅用于歌曲元数据与歌词；支持逐字/逐行歌词、可用翻译及音译。
- 增加中英文名称、繁简体与地区信息辅助匹配，并提供搜索/单曲链接/歌曲 ID 手动匹配、预览和按歌曲记忆。
- 无歌词时仍可按歌曲信息生成 AI 主题；服务未配置时明确使用封面取色备用主题。
- 删除无效音质切换，由系统“音乐”App 管理音质。
- 独立源码构建及 DMG 打包，不需要原版 Folia；关闭指向原版的更新检查。

## 安装

下载 `Folia-Apple-Music-0.7.20-applemusic.beta.2-macOS-arm64.dmg`，将应用拖入“应用程序”。本测试版没有 Developer ID 签名或 Apple 公证；系统可能阻止首次打开，需要使用者核对来源后自行处理系统提示。不会安装关闭系统安全保护的脚本。

首次运行需要你在系统“音乐”中登录自己的 Apple 账号，订阅歌曲需要有效 Apple Music 会员；允许应用控制“音乐”。未加入资料库的目录歌曲请先通过系统“音乐”加入资料库。

## 范围与限制

- 当前只提供 Apple Silicon arm64 包；运行时声明 macOS 12+，未在全部受声明支持的 macOS 版本或另一台实体 Mac 验证，不提供未经实机验证的 Intel 包。
- 网易云的歌词覆盖、地区与版本不同；不能保证每首歌匹配。限流或缺词时可稍后重试或手动导入。
- AI 模型服务需要用户自行配置；安装包没有共享密钥。
- Apple Music 不提供本地 PCM，本版不支持从受保护音频进行声部分离、音频导出或精确音频分析；原有相关代码保留。
- 本机全新配置测试曾出现连接状态短暂未就绪，重连后搜索通过；若显示未连接，可点击资料库连接图标重试。
- 系统自动化/钥匙串授权由使用者完成，更新临时签名后可能再次询问。软件为测试版，无零故障承诺。
