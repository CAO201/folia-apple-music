This distribution retains the original Folia acknowledgements in `README.upstream.md`, the full original `LICENSE`, and `NOTICE.md`. Do not remove them from a redistributed edition.

- **Electron / Chromium / Node.js**: Electron is MIT licensed; Chromium and Node.js include multiple third-party licenses. The Electron runtime supplies its original license materials. Copies are also collected under the app's `Contents/Resources/licenses/` directory.
- **npm dependencies**, including React, the Folia visualizer/lyrics dependencies, NetEase metadata API adapter, ONNX Runtime and Koffi: exact versions and download integrity records are pinned in `package-lock.json`. `npm run apple:notices` collects the installed packages' unchanged license/notice texts and package source references into `release-materials/licenses/INDEX.json`; these are included in the app. This inventory intentionally also includes build-only packages, so it is broader than the runtime bundle.
- **Folia FFmpeg build**: the pinned audio runtime is fetched and checksum verified by `packaging/ffmpeg/fetch-ffmpeg.mjs`. Its bundled license/build/source metadata is retained in `Contents/Resources/ffmpeg-audio/`. Upstream build recipes: https://github.com/chthollyphile/folia-ffmpeg-build . This build declares LGPL-2.1-or-later; the exact FFmpeg source archive and locked build recipes are provided in `Contents/Resources/third-party-sources/`, with source hashes in `SOURCE-INFO.json`. Its original license continues to apply; this app's AGPL license does not replace it.
- **Model assets**: model downloading, source references, hashes and declared licenses remain in `shared/modelManifest.json`. Model weights and optional Python runtimes are not bundled in this test release; their existing opt-in downloader remains available where applicable. Apple Music's protected audio is not exposed as a PCM file to analysis/export features.
- **Fonts, icons, mod assets and vendored components**: retain their source-adjacent licenses, comments and credits, including `mods/visualizer52hz/vendor/PIXI-LICENSE` and `dev/icuFolia/jieba/LICENSE`. Build scripts preserve repository attribution files.

Apple Music playback is provided by the user's macOS Music app and subscription. NetEase supplies only requested metadata/lyrics; no audio from NetEase, QQ, KuGou or Bodian is played by this edition. Lyrics and cover artwork are not included in the source or installer as a redistributed music collection.
